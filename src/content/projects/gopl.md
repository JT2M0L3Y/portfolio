I am porting the MyPL interpreter to Go as a way to learn Go idioms while building a language toolchain. The project includes a lexer, parser and AST, semantic checks, code generation, and a virtual machine, with tests, CI, and profiling workflows.

The Go implementation is ongoing; see the repository for its current state.
